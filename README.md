# Gate Pass Visitor Management System

A comprehensive MERN stack application for managing visitors in gated communities, corporate offices, and educational institutions.

## Features

- **Authentication & Roles**: JWT-based authentication with Admin, Guard, and Resident roles
- **Visitor Management**: Pre-approved and walk-in visitor registration
- **QR Code System**: Generate and scan QR codes for entry/exit validation
- **Analytics Dashboard**: Real-time statistics and visualizations
- **Email Notifications**: Automatic notifications for visitor arrivals

## Tech Stack

- **Frontend**: React, Tailwind CSS, Chart.js, React Router
- **Backend**: Node.js, Express, MongoDB, Mongoose
- **Authentication**: JWT, bcrypt
- **Deployment**: Docker, MongoDB Atlas, Render/Vercel
